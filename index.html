How it was made

Every frame is rendered by Python (Pillow + numpy) at 1920×1080: a procedurally generated newsprint texture, Georgia set in ink #141414 with one accent #B23A2F, kinetic type driven by eased time curves, then piped as raw RGB into ffmpeg at exactly 1800 frames. The voice is a neutral en-GB read; the bed (room tone, page rustle, typewriter ticks, low drone) is synthesised in numpy, so no third-party audio is used. Nothing in this film is generated footage, so the transcript above is the full spoken content.
